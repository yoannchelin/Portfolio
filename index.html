Git Archaeologist — a 5-agent ecosystem for understanding legacy code

Go • MCP • Local LLM

LLMs read 200 lines well and 200k-line repos badly. Archaeologist indexes a repository's call graph, vector embeddings and git history into SQLite, then exposes it over the Model Context Protocol so any MCP client (Claude, Cursor, Zed) can answer "where is payment handled?" or "what breaks if I rename this?". Four more agents build on that same index. Everything runs on-prem against a local LLM — no code leaves the machine.

Git Archaeologist Hybrid retrieval — vector + lexical + call graph — served over MCP. Blast Radius Reverse call-graph impact analysis, 0–100 risk scoring, tests-to-rerun. No LLM, pure SQL + graph. Bug Hunter Fix hotspots, silent error handling (Go AST / TS / Python), bus-factor-1 files, implicit coupling. Test Sentinel Semantic coverage quality: untested critical functions, unexercised error paths, assertion-free tests. Dep Sentinel CVEs via govulncheck (OSV fallback), copyleft licence flags, outdated modules — no paid API.
